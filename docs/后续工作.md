## `TODO 未校对` 处理规则

- 只有阶段 5 已校对译文可以直接接入游戏。
- 阶段 5 以外的内容保留原文，并标记 `TODO 未校对`。
- 即使由开发者自行翻译，也必须保留 `TODO 未校对`，直到人工校对完成。
- 实机排版检查只能证明文字没有重叠、截断或错误换行，不能代替译文校对。
- 当前 TODO 中包含阶段 2 文本、额外关卡、未使用台词和旧歌词，不应为了清空数量而强行翻译。
- 可以通过搜索 `TODO 未校对` 查看所有尚未校对或尚待控制码复核的项目。
- 图片文字翻译暂不处理。

## 每完成一组后的处理步骤

1. 只在确认实际画面正常后删除对应的排版 TODO。
2. 在源码旁添加中文注释，说明改了什么、为什么修改以及如何验证。
3. 将实机截图保存到 `docs/qa/`。
4. 更新 `docs/报告.md` 和本文件中的复选框。
5. 运行译文导入检查、缺字检查和控制码检查。
6. 编译 PLAYTEST 与 PARADISE 两个版本并确认 ROM 可以运行。
7. 运行 `git diff --check`，防止出现空白或格式问题。
8. 使用中文提交信息记录修改原因、具体改动和验证结果。
